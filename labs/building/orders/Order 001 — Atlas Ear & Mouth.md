

## Goal

Build the first physical input and output interfaces of Atlas.

The first milestone is:

Voice → Microphone → ESP32-S3 → Mac → Whisper

Later:

Mac / ESP32-S3 → Amplifier → Speaker

## Ordered Parts

### ESP32-S3 DevKitC

- ESP32-S3-WROOM-2
- 32 MB Flash
- 16 MB PSRAM
- Main microcontroller development board for the first Atlas prototype
- Cost: $19.95

### I2S MEMS Microphone

- SPH0645LM4H
- Digital I2S microphone
- Will act as Atlas's first physical ear
- Cost: $6.95

### MAX98357A

- I2S Class D amplifier
- Will receive digital audio and drive the speaker
- Cost: $5.95

### Speaker

- 4 Ohm
- 3 Watt
- Will act as Atlas's first physical voice output
- Cost: $3.95

### Breadboard

- Full size
- 830 points
- Used for prototyping without permanently connecting components
- Cost: $5.95

### Male to Male Jumper Wires

- Used for breadboard connections
- Cost: $3.95

### Male to Female Jumper Wires

- Used for connections between headers and breadboard components
- Cost: $1.95

### Female to Female Jumper Wires

- Used for direct connections between header pins
- Cost: $1.95

### Soldering Iron

- Adjustable temperature
- 60 W
- Used to solder headers and future electronic components
- Cost: $19.95

### USB Cable

- USB-C to Micro USB
- Power + data
- Used to connect the ESP32-S3 to the Mac
- Cost: $3.50
